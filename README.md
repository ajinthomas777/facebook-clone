# Facebook Homepage Clone

A responsive Facebook-inspired homepage clone developed using HTML, CSS, and Vanilla JavaScript as part of the Trackpi Internship Technical Assignment.

## Features

- Facebook-inspired homepage layout
- Navigation bar and sidebars
- Stories section
- Dynamic news feed with at least five sample posts
- Create new text posts
- Like and unlike functionality
- Comment interaction
- Share post link functionality
- Light and dark mode toggle
- Theme preference persistence using localStorage
- Responsive layout for desktop and mobile devices

## Technologies Used

- HTML5 – Page structure
- CSS3 – Styling, layouts, CSS variables, and responsive design
- JavaScript (Vanilla JS) – DOM manipulation and event handling
- localStorage – Persistent theme preference
- Git and GitHub – Version control and source code hosting

   ```bash

   ```

2. Navigate to the project directory:

   ```bash
   cd facebook-clone
   ```

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.

## Implementation Approach

The project was developed using HTML, CSS, and Vanilla JavaScript without any external frameworks or libraries.

HTML provides the structure of the homepage, including the navigation bar, sidebars, stories, and news feed.

CSS is used to recreate the Facebook-inspired interface, manage layouts, and implement light and dark themes using CSS custom properties.

JavaScript dynamically generates posts from an array of objects and handles user interactions such as liking, commenting, sharing, and creating posts.

The dark mode preference is stored in browser localStorage so that the selected theme remains active after refreshing the page.

## Challenges

- Recreating a familiar social media interface using only HTML and CSS.
- Dynamically generating multiple posts using JavaScript and DOM manipulation.
- Implementing interactive like, comment, and share functionality.
- Managing light and dark themes using CSS variables.
- Persisting user theme preferences using localStorage.
- Making the homepage responsive across different screen sizes.
